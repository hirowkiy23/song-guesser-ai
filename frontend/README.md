# 🎵 Song Guesser AI

A full-stack web application that predicts song titles based on user-submitted lyrics.

## Tech Stack

- Backend: FastAPI (Python)
- Frontend: React (Vite)
- Communication: REST API
- Architecture: Layered backend (models, services, database)

## Features

- Lyric-based song prediction
- Confidence score output
- Structured API responses
- Full frontend-backend integration

## How to Run

### Backend
cd backend
python -m uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm run dev
